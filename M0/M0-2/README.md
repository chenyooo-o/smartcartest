# M0-2 首个代码工具：相关系数计算重构版

## 1. 如何运行

使用 `uv` 进行环境管理。具体步骤：

```bash
# 1. 创建虚拟环境
uv venv

# 2. 激活虚拟环境
source .venv/bin/activate

# 3. 初始化项目并添加依赖
uv init
uv add numpy pyyaml

# 4. 运行程序
python3 legacy_corr.py --config config.yaml
```

## 2. 输入格式要求

### (1) YAML 配置文件 (`config.yaml`)
包含以下内容：
* `input_csv`：指定输入的 CSV 文件名（支持相对路径）。
* `columns`：一个字典，包含需要计算的两列的列名。
  * `x`：X 轴的列名（如 `"sensor_a"`）。
  * `y`：Y 轴的列名（如 `"sensor_b"`）。

> **路径优化说明**：利用 `os.path.abspath` 进行了优化。若 `input_csv` 填写的是相对路径，程序会以 YAML 配置文件所在的目录为基准去寻找 CSV 文件，确保在跨目录调用时不会迷路。

### (2) CSV 数据文件
* 文件必须包含表头。
* 表头中必须包含 YAML 中 `x` 和 `y` 所指定的列名，且**列名大小写、拼写必须完全一致**。
* 指定的列中必须全是能够转换为浮点数的数据格式，不能包含字母或乱码。

## 3. 输出含义

程序运行成功后，会输出以下内容：
* `n = <数值>`：参与计算的样本数量（数据行数）。
* `mean_x = <数值>`：X 轴数据的算术平均值。
* `mean_y = <数值>`：Y 轴数据的算术平均值。
* `r = <数值>`：皮尔逊相关系数（Pearson Correlation Coefficient）。

**关于相关系数 `r` 的解读：**
* **取值范围**：`-1.0 ≤ r ≤ 1.0`
* `r > 0`：正相关。越接近 1.0，正相关性越强。
* `r < 0`：负相关。越接近 -1.0，负相关性越强。
* `r ≈ 0`：无明显线性相关关系。

## 4. AI 使用情况

在本次作业中使用了 AI 辅助，具体情况如下：
* AI 提供了 `try-except` 的范式，在此基础上，我补充了 `exit(1)` 逻辑，确保不抛出 Traceback。
* 尝试运行时报错“找不到 config.yaml 文件”。经询问 AI，发现是因为程序默认以终端当前目录去寻找 CSV 文件。在 AI 的提示下，我加上了 `os.path.abspath`，解决了跨目录调用的路径问题。
